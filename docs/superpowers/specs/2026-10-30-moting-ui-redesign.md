# Moting 界面重设计（已确认）

> 日期：2026-10-30
> 状态：用户确认（"效果不错，按这套 UI 执行"）
> 设计稿：`docs/superpowers/design/2026-10-30-moting-ui.html`（在浏览器中打开）
> 补充：`docs/superpowers/specs/2026-10-30-moting-design.md`

## 意图

当前界面"太基础、没设计"。新界面要像一个现代的 Mac app，向 macOS 26 的 Liquid Glass 风格靠拢，但仍然克制、遵循原生规范。辨识度只集中在一处：**双声道声纹带**。

## 视觉体系

- **色彩**：沿用图标的配色。
  - 我：浅色 `#0FA3D8`，深色 `#3CD3FE`
  - 对方 / 说话人 1：浅色 `#C99700`，深色 `#FFD600`
  - 说话人 2：`#F27A5E`
  - 说话人 3：`#A27BFF`
  - 说话人 4 及以后循环使用 `#5ED39A`、`#FF6FAE`、`#7FB2FF`
  - 录音红：`#FF383C`
  - 浅色背景上文字一律用加深版，亮色只用于填充。
- **字体**：系统字体（SF Pro + 苹方）；计时、时间戳一律用等宽数字（`monospacedDigit`）。
- **材质**：macOS 15 上用 `.ultraThinMaterial` / `.regularMaterial` 加细描边、内高光，模拟玻璃效果；侧栏做成浮在窗口内的圆角玻璃面板。系统和 Xcode 升级到 26 后，改用 `glassEffect`。
- **深浅色**：都支持，跟随系统。

## 画面（以设计稿为准）

1. **主窗口**：统一工具栏，内容为导出、重新转写、更多，以及红色"开始录音"胶囊按钮；录音中该按钮变为计时和结束。
   - **侧栏**：
     - 顶部搜索框，能搜会议标题和转写内容
     - 会议按今天 / 昨天 / 本周 / 更早分组
     - 每行显示标题、状态标签（转写中 N% / 等待电源 / 录音中 / 失败）、时间、时长、人数，下方一条迷你声纹条（按时间显示谁在说）
     - 底部常驻存储用量卡片，点"管理"打开设置 → 存储
   - **详情**：
     - 大标题（铅笔改名）
     - 元信息：日期时间，以及参会人彩色圆点和名字
     - **声纹带播放器**：播放键、当前 / 总时长、上半"我"、下半对方（按说话人着色），★ 标记位置，已播放部分全色、未播放部分淡化；点击或拖动任意位置跳转
     - 处理进度横幅
     - 页签：纪要 / 转写稿 / 标记 N
     - 转写稿右上角是版本切换（精准 / 实时草稿）
     - 转写稿每行：时间、说话人色条加名字、文字；当前句高亮；点句播放
     - 标记页：每个标记显示时间和附近的原话，点击跳转
     - 纪要页：P4 之前为空状态，说明"AI 纪要将在接入后生成"
2. **悬浮字幕窗**：圆角 18 的玻璃卡片。
   - 头部：红点、计时、两路电平、★、收起
   - 字幕：说话人名按颜色区分，未定稿的部分半透明
   - 底部：标记、暂停、结束
   - 收起后为胶囊：红点、计时、最新一句、停止
   - 录音结束后显示精准转写进度（进度条和提示），完成后自动收起
3. **菜单栏面板**：`MenuBarExtra` 的窗口样式。
   - 平时：大号"开始录音"按钮（⌥⌘R）、最近 3 场会议及状态、"打开 Moting"、"设置…"
   - 录音中：菜单栏直接显示红点和计时；面板显示计时、暂停 / 结束、最新两句字幕、★ 标记、显示字幕窗
4. **设置**：系统设置样式的左侧分栏。分栏项为通用、识别模型、AI 纪要、热词与声纹、存储、下载。
   - **识别模型**：实时和离线各一组，每个模型显示实测准确率条（字错率换算成准确率，越长越准）、处理 1 小时会议的时间、大小、是否支持热词，以及下载 / 删除 / 选用。数字来自会议测试集评测；没有评测过的模型不显示数字。
   - **存储**：
     - 总占用大字，分类占比条：录音 / 在用模型 / 未使用模型 / 辅助模型 / 其他
     - "可以释放 X"加"清理未使用的模型"
     - 逐项列表，标"在用 / 未使用"，可删除
     - 文件夹路径、在 Finder 中显示、"删除 Moting 全部数据…"（二次确认）
   - **AI 纪要**：P4 之前只放说明。
   - **通用**：录音结束后自动精准转写（开关），用电池时的处理方式（等插电 / 立即）。

## 数据可见与不乱放文件（硬性）

- 新增的缓存（如声纹带波形）只放在内存，或放在会议自己的目录里，随会议删除而删除。
- 下载时 `URLSession` 不写系统网络缓存。
- "删除全部数据"会删除 `~/Library/Application Support/Moting/`，以及 `~/Library/Caches/com.lidedongsn.moting`。

## 不做

- 真正的 Liquid Glass 接口：需要 macOS 26 / Xcode 26。
- AI 纪要内容：属于 P4，这里只做页面框架和空状态。
- 全文搜索索引：先用 SQL 的 LIKE 搜索，数据量大了再上 FTS5。
