# 待办（审阅中暂缓的小问题）

## 来自 P1 审阅
- 某一路启动失败时消费定时器泄漏
- 创建会议中途失败会留下"录音中"记录
- 系统音频重建失败后不重试
- 换麦克风后旧设备的采样率监听不注销
- IOProc 中 takeUnretainedValue 可能产生引用计数操作
- 启动过程中退出会留下"录音中断"记录
- 权限被拒时多出"失败"会议和空目录
- 磁盘写满部分写入后样本计数与文件不一致
- 麦克风授权用信号量阻塞协作线程

## 来自 P2 审阅
- 模型校验失败时不换下一个镜像
- 录音中删除 / 切换模型时字幕区被提示替换
- 旧模型加载失败可能覆盖新模型状态；未知模型 id 卡在"加载中"
- 详情页每次重绘扫描会议目录
- 暂停回放后音频引擎一直运行
- 录音中的会议回放时长不刷新
- 草稿片段落库失败被静默吞掉
- sherpa 静态库下载未校验 SHA-256、仅 arm64
- 被挤出字幕缓冲的句子迟到定稿时顺序错乱

## 延后的验证
- 共享屏幕时悬浮窗是否被采集（飞书会议、腾讯会议，整屏 / 窗口两种）
- 实时识别性能实测（录 5 分钟，CPU ≤ 单核 30%、内存 ≤ 600MB）
- 采样率跟随：戴 AirPods 开会时"对方"一路是否正常
