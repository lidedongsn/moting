Moting — 安装与首次使用

系统要求
  Apple Silicon Mac（M 系列芯片），macOS 14.2 或更新版本。
  当前安装包不支持 Intel Mac。首次下载语音模型需要联网。

安装
  1. 解压下载的 ZIP 文件。
  2. 将 Moting.app 拖入“应用程序”文件夹，再从该位置打开。
  3. 按应用引导授予麦克风和系统音频录制权限，并下载需要的模型。
  4. 如需 AI 纪要，在设置中配置所选服务或本机 Ollama。

签名与首次打开
  此版本采用临时签名，未使用 Developer ID 证书，也未经 Apple 公证。
  macOS 可能阻止首次打开。确认文件来自本项目发布页且校验一致后，
  可按 Apple 官方说明在“系统设置 → 隐私与安全性”中选择“仍要打开”。
  不需要关闭系统安全保护，也不需要在终端运行解除限制的命令。
  Apple 说明：https://support.apple.com/zh-cn/102445

校验下载文件
  发布页同时提供 .sha256 文件。将 ZIP 和校验文件放在同一目录，执行：
  shasum -a 256 -c Moting-0.1.0-macOS-arm64.zip.sha256

数据
  应用将会议、数据库、模型和声纹保存在当前用户的
  ~/Library/Application Support/Moting/ 目录中。
  安装包不包含会议数据、识别模型或 API Key。
  语音识别在本机执行；远程 AI 纪要会将转写文本发送到所选服务。
