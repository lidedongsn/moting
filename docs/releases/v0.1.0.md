# Moting 0.1.0

首个可下载安装的 macOS 版本。

## 下载与安装

下载附件 **Moting-0.1.0-macOS-arm64.zip**，解压后将 `Moting.app` 拖入“应用程序”文件夹。

- 支持 Apple Silicon（M 系列芯片）和 macOS 14.2 及以上版本；不支持 Intel Mac。
- 安装后按引导授予麦克风和系统音频录制权限，并下载所需识别模型。
- 使用 AI 纪要时，需要自行配置兼容服务或本机 Ollama。

## 功能

- 麦克风与系统音频双路录音、菜单栏控制和全局快捷键 `⌥⌘R`。
- 本机实时字幕、会后转写、说话人区分与个人声纹匹配。
- 会议回放、转写稿编辑、复制与 Markdown 导出。
- 可配置的 AI 纪要服务、模型管理和存储用量查看。
- 简体中文与英文界面。

## 首次打开

此安装包采用临时签名，**未经 Developer ID 签名和 Apple 公证**。macOS 可能阻止首次打开。确认下载来源和校验值后，可参照 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，在“系统设置 → 隐私与安全性”中选择“仍要打开”。无需关闭 Gatekeeper 或在终端运行解除限制的命令。

## 校验与隐私

同时下载附件中的 `.sha256` 文件，在文件所在目录执行：

```sh
shasum -a 256 -c Moting-0.1.0-macOS-arm64.zip.sha256
```

安装包不包含会议数据、API Key、签名证书或识别模型。语音识别在本机执行；远程 AI 纪要会将转写文本发送到所选服务。
